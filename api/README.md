# api/

The managed Azure Functions app that Azure Static Web Apps runs for Agent-Ready Check.

- `dist/index.mjs` is generated by `npm run build:azure` (it bundles `server/azure-function.mjs` and the checker). It is not committed.
- `@azure/functions` is the only runtime dependency installed here (`npm ci --prefix api` or `npm install --prefix api`).
- One HTTP function, `site`, answers `/api/{*path}`. Static Web Apps rewrites every page that is not under `/assets/` or `/api/` to `/api/__site`, and the function serves the original address from the `x-ms-original-url` header. See `server/azure.mjs`.

Deployment is done by `.github/workflows/deploy-azure.yml`. See `docs/PUBLISHING.md`.
